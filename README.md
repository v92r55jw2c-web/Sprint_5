# Sprint 5 — Автоматизация тестирования Stellar Burgers
Проект выполнен в рамках учебного задания Sprint 5.

## Описание проекта

Проект содержит UI-автотесты для веб-приложения [Stellar Burgers](https://stellarburgers.education-services.ru/).

В рамках проекта автоматизировано тестирование регистрации, авторизации, переходов между разделами сайта, выхода из аккаунта и навигации по конструктору бургеров.

## Что проверяют тесты

### Регистрация
- успешная регистрация пользователя;
- регистрация с некорректным паролем.

### Авторизация
Проверяется вход в аккаунт:
- через кнопку «Войти в аккаунт» на главной странице;
- через кнопку «Войти» в форме регистрации;
- через кнопку «Войти» в форме восстановления пароля;
- через раздел «Личный кабинет».

### Личный кабинет
- переход в личный кабинет;
- выход из аккаунта.

### Переходы между разделами
- переход из личного кабинета в конструктор через кнопку «Конструктор»;
- переход из личного кабинета в конструктор через логотип Stellar Burgers.

### Разделы конструктора
Проверяется переход между разделами:
- «Булки»;
- «Соусы»;
- «Начинки».

## Технологии
- Python 3.9
- Selenium 4
- Pytest
- Chrome WebDriver
